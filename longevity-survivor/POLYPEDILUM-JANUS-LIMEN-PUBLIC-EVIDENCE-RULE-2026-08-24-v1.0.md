# POLYPEDILUM / Pv11 — JANUS LIMEN OF THE THIRD DOOR

Status: **PUBLIC EVIDENCE POLICY**

The public branch admits only material with public provenance or explicit authorization. No other material receives public evidentiary weight, attribution, description, or encoded payload.

```text
LIMEN_CLOSED
SHADOW_WEIGHT = 0
UNKNOWN_STAYS_UNKNOWN
THE_ORACLE_DOES_NOT_NAME_THE_UNSEEN
THE_SUN_DOES_NOT_INDEX_THE_SHADOW
```

In practical terms:

- public claims must be reproducible from cited public sources or explicitly authorized material;
- unavailable evidence is not reconstructed from hints;
- absence of a public measurement remains `UNKNOWN`, not a guessed value;
- public artifacts carry no reversible encoding of non-admitted material.

This is an evidence-governance rule, not a scientific observation.
